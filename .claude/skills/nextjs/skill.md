# Next.js Skill

## Overview
This skill provides expertise in Next.js development, including the App Router, Server Components, Client Components, routing, data fetching, and best practices.

## Capabilities
- Implement Next.js applications using the App Router (/app directory)
- Create Server Components for efficient rendering and data fetching
- Develop Client Components for interactive elements
- Set up routing and navigation with Next.js conventions
- Handle form submissions and API integration
- Implement responsive design with modern CSS frameworks
- Optimize performance and handle loading states
- Integrate with backend APIs and authentication systems

## Best Practices
- Use Server Components by default for better performance
- Leverage Client Components only when interactivity is required
- Follow Next.js file-based routing conventions
- Implement proper error boundaries and loading states
- Use TypeScript for type safety
- Apply responsive design principles
- Handle SEO and meta tags appropriately

## Common Patterns
- Layouts and templates in the App Router
- Data fetching with async/await in Server Components
- use client directive for Client Components
- Form handling with React Hook Form or native forms
- API routes for backend functionality
- Environment variable management
- Static and dynamic imports

## Integration Points
- Connect with backend APIs
- Integrate authentication systems
- Handle file uploads and static assets
- Implement internationalization (i18n)
- Add analytics and monitoring
- Set up testing environments
